# 校园术语库（Campus Terminology）

让 LibreTranslate 在中俄方向**优先采用学校自己的标准译法**。

---

## 为什么需要它

LibreTranslate 的官方模型库里**没有中俄直连模型**，中译俄的真实链路是：

```
中文 →[zh_en 模型]→ 英文 →[en_ru 模型]→ 俄语
```

两次翻译中，专业术语会被当作普通词处理，误差逐层放大。

**实测结果（6 句真实校园通知，26 个术语位置）：**

| | 术语译法正确率 |
|---|---|
| 原版 LibreTranslate | **0 / 26 = 0.0%** |
| 加入校园术语库后 | **23 / 26 = 88.5%** |

典型翻车案例：

| 中文 | 原版译文（错） | 术语库译文（对） |
|---|---|---|
| 计算机组成原理 | `компьютерной композиции` / 回译成「计算机参谋学院」 | `Архитектура компьютера` |
| 选课 | `занятиями`（上课）—— 静默丢失含义 | `выбор курса` |
| 成绩 | `достижений`（成就） | `оценка` |
| 第二教学楼 | `второй школы`（第二中学） | `Второй учебный корпус` |
| 教室 | `класс`（班级） | `аудитория` |

## 工作原理

**翻译前**把命中的术语换成占位符，让模型完全碰不到它；**翻译后**再换回目标语言的术语。

```
原文：  请同学们在 选课 前完成俄语水平测试
  ↓ mask()
送入：  请同学们在 @1@ 前完成@2@水平测试
  ↓ 模型翻译（不认识 @1@，原样带过去）
译出：  Студенты должны пройти тестирование по @1@ ...
  ↓ unmask()
结果：  Студенты должны пройти тестирование по выбор курса ...
```

### 占位符格式是压测出来的

第一轮（一句话 1 个占位符）—— 大部分格式都能活：

| 格式 | 结果 |
|---|---|
| `<7>` | ✅ 存活 |
| `[[7]]` | ❌ 被吃成 `[7]` |
| `⟦7⟧` | ❌ 变成 `7-летием`（七周年） |
| `{7}` | ❌ 变成 `77` |
| `#7#` | ❌ 变成 `#7` |

第二轮（一句话 5 个占位符，更接近真实情况）—— 只剩一个能打：

| 格式 | 存活率 |
|---|---|
| **`@1@ @2@ @3@ …`** | **5/5 ✅** |
| `<1> … <5>` | 3/5 ⚠️ |
| `[[1]] … [[5]]` | 3/5 ⚠️ |
| `{{1}}`/`#T1#`/`~1~`/`※1※`/`__1__`/`<<1>>` | 0/5 ❌ |

第三轮（真实中文句子，无空格）—— 确认「不要加空格」：

| 写法 | 存活率 |
|---|---|
| `@1@` 直接替换 | **15/16（94%）** |
| `␣@1@␣` 前后补空格 | 2/16（12%） |
| `〖@1@〗` 特殊符号包裹 | 0/16 |

**结论：用 `@数字@`，直接替换，不补空格。**

### 双方案自动兜底

实测发现「丢词」是**方案相关**的：数字方案弄丢「教学大纲」，字母方案弄丢「选课、俄语」。
所以模块内置两套编号方案，翻译后发现术语没保住时自动换另一套重试一次：

- 方案 0：`@1@ @2@ @3@`（数字）
- 方案 1：`@a@ @b@ @c@`（字母）

设计原则：**术语要么正确，要么明确报告失败，绝不静默出错。**
这条原则来自实验中的一个发现 —— 校园场景里最危险的错误不是明显翻错，
而是「选课」被悄悄翻成「上课」：句子通顺、语法正确，但学生会被误导且无法察觉。

## 术语表怎么维护

术语表是**独立的 CSV 文件**，与代码完全分离：

```
terminology/campus_terms.csv
```

| 列 | 说明 |
|---|---|
| `zh` | 中文术语（必填） |
| `ru` | 俄语标准译法 |
| `en` | 英文译法 |
| `category` | 分类：课程名 / 教务流程 / 校园设施 |
| `note` | 备注（可写实测翻车情况，方便说明为什么收录） |

**教务老师或俄方教师可以直接用 Excel 编辑，不需要碰代码、不需要重新部署。**
服务下次启动时自动读取。

也可以指向别的文件：

```bash
export LIBRETRANSLATE_TERMINOLOGY=/path/to/your_terms.csv
```

临时关掉术语库：

```bash
export LIBRETRANSLATE_DISABLE_TERMINOLOGY=1
```

## 已知局限（如实说明）

1. **格变化**：俄语名词在主格/属格/宾格形态不同。本模块填回的是术语的**基础形式**，
   若上下文要求其他格，语法可能不完美。第一期只保证**术语词本身不会翻错**。
   二期方案：给每个术语维护词形表。
2. **术语周围的句子**仍走「中→英→俄」两次翻译，语序和虚词仍可能不自然。
   本模块解决的是「术语翻错」，不是「整句语法完美」。
3. **覆盖率**：当前 50 个高频词。术语表没收录的词，行为与原版一致。
